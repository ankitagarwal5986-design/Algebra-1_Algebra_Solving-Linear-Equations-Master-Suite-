📐 Paul's Online Notes: Solving Linear Equations Compendium

A linear equation in one variable is an equation that can be written in the form \(ax + b = 0\) where \(a \ne 0\). The goal is to isolate the variable using reversible algebraic operations.

1. Standard Solution Procedure

1. Clear fractions or decimals by multiplying every term by the LCD.

2. Clear all parentheses using the distributive law.

3. Combine like terms on each side independently.

4. Collect variable terms on one side and constant terms on the other.

5. Divide by the coefficient of the variable to isolate it.

2. Clearing Denominators with LCD

For equations containing fractions:

\[\frac{x}{a} + \frac{y}{b} = c \implies \text{LCD}(a, b) \cdot \left(\frac{x}{a} + \frac{y}{b}\right) = \text{LCD}(a, b) \cdot c\]

Eliminates all denominators in a single step, yielding integer coefficients.

3. Classification of Linear Equations

Linear equations have three possible solution sets:

• Conditional: Exactly one unique solution \(x = c\).

• Identity: Variables cancel leaving a true statement like \(0 = 0\) (Solution set: all real numbers \(\mathbb{R}\)).

• Contradiction: Variables cancel leaving a false statement like \(0 = 7\) (No solution, empty set \(\emptyset\)).
